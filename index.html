ABOUT / 关于

把一件事从 0 做到上线

我是 Bixike，一名 Full-stack Engineer，专注用现代前端与云原生后端构建真正可落地的校园产品——不是 demo，是面向真实用户的生产级工程。

独立完成并上线「堡到校园」：一个覆盖即时跑腿（Errand）、校园订餐（Meal Pickup）、校园墙（Community）、失物招领（Lost & Found）、二手闲置（Second-hand）与资讯的综合服务平台。技术栈为 uni-app + Vue 3 + uniCloud，一套源码双端发布，另含基于 Vite + Vue 3 的运营中台（Admin Console）与官网。

工程侧坚持云端鉴权、事务与幂等、支付安全框架、内容风控、审计日志与自动化测试矩阵——一切面向 production 而非演示。
