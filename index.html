关于我

我是 Bixike，独立做完了「堡到校园」并把它上线——一个面向大学生的校园综合服务平台，覆盖跑腿、校园订餐、校园墙、失物招领、二手闲置、资讯与商家系统。

技术栈是 uni-app + Vue 3 + uniCloud（支付宝云）+ 微信小程序 / Android 双端，另有一套基于 Vite + Vue 3 的 Web 运营后台和官网。整个项目按生产级标准推进：云端鉴权、事务与幂等、支付安全框架、内容风控、审计日志、自动化测试与包体门禁，都是真实地在跑。
